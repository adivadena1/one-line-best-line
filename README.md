# One Line, Best Line

An entry for the [make.fun "One Line, Best Line" bounty](https://make.fun/bounty/u-gudril-cool-one-line-best-line-b8c41f4d).

The program (`main.ts`, Node 22, standard library only) writes one original line of text to `/output/entry.txt`:

> My goldfish filed for custody of the cat, and the judge ruled the bowl was the only honest room in the house.

109 characters, one sentence. The line is a constant in the program, so every run writes the same bytes — deterministic, no network, no clock, no randomness.
